# Security

## Reporting a flaw in the specification

If you find a weakness in Proof of Persistence itself (a way to obtain a `proven` Determination the evidence does not support, hide a `refuted` or `insufficient` result, use evidence produced before the Claim Declaration, or compute a Determination a verifier would not), report it privately to the maintainer, Craig Thomas Ellrod, before public disclosure. Open a GitHub security advisory on this repository or contact the maintainer directly.

## Payloads

Basis records may include embargoed canaries under PP-SPEC-077. This repository never contains canary contents, embargoed details, or exploit code. Do not submit them in issues or pull requests.
